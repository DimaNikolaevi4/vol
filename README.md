# vol — паспорта учебных программ (новая редакция)

**Идея:** привести паспорта образовательных программ к новой редакции — сначала один эталонный паспорт, затем по нему остальные (~9 штук). Пилот — программа повышения квалификации **18494 «Слесарь по контрольно-измерительным приборам и автоматике»**.

## Что реализовано

В репозитории полный комплект учебной документации: три профессии × три вида обучения (П / ПП / КПК), нормативная база, скрипты ФОС, правила и чек-листы.

## Задача 1 — паспорт программы 18494

- Форма: паспорт программы повышения квалификации по новой редакции.
- Результат: один полностью готовый паспорт, который станет образцом для остальных.
- Срок: **20.11.2026** (перенесён с 25.11 по указанию владельца 17.11; 25.11 — только запас). Работа ежедневно 18–20.11.
- Пилотная папка: `Слесарь по контрольно-измерительным приборам и автоматике/повышение квалификации   18494 Слесарь КИПиА/` — 26 файлов: `00`, `01`, `02`, `03`–`05`, 8 лекций ОП + 12 лекций МДК.

## Задача 2 — методика

После первого паспорта зафиксировать: какие разделы меняются, в каком порядке, что проверяется на выходе. Это ускорит оставшиеся ~9 паспортов.

## Статус

- **origin — источник истины** (решение владельца 18.11.2026); локальная копия выровнена (`main == origin/main`).
- Степень реализации: учебная документация в репозитории; **паспорт по новой редакции ещё не подготовлен**.
- ⚠️ В репозитории включён `core.longpaths=true` — без него checkout падает на длинных кириллических путях (`Filename too long`).
- Открытый вопрос: образца «новой редакции» паспорта в репозитории нет — уточнить у владельца (файл или требования).
