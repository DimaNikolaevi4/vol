## 7. Правила работы с репозиторием (жёсткие)

- **`origin` — источник истины.** Перед работой: `git fetch --all --prune`, `git status`, `git log HEAD..origin/main --oneline`. При расхождении — доложить, не решать самому.
- **`core.longpaths=true` обязателен** — иначе checkout падает на длинных кириллических путях.
- **Никогда `git add -A`**: 18.11 такая команда удалила 328 файлов («инцидент vol»). Только адресный `git add` конкретных файлов, перед коммитом — `git diff --cached --stat` и проверка, что нет строк `D `.
- **PowerShell 5.1**: `.ps1` с кириллицей сохранять в UTF-8 **с BOM**; вывод git в консоли ломает кириллицу — перенаправлять в UTF-8-файл или читать через Python.
- **Word COM** используется только для обновления полей/оглавления (`scripts/update_fields_word.ps1`); после него закрывать Word, иначе остаётся `~$` lock-файл (он в `.gitignore`).
- Правки `.docx` — только скриптами на `python-docx`, без ручного редактирования; каждый прогон проверять `verify_kpk_00_program.py`.
- Резервные ветки на всякий случай: `backup/local-before-origin-20261118`, `backup/local-before-sync-20261118`.
