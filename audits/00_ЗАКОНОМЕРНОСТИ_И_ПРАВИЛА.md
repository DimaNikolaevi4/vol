# Закономерности и правила оформления учебной документации

## 1. Общая структура репозитория

Репозиторий содержит комплекты учебной документации для профессий промышленного профиля. Каждая профессия — это отдельная папка верхнего уровня, внутри которой находятся 2-3 подпапки по видам обучения:

| Подпапка | Префикс файлов | Расшифровка |
|---|---|---|
| профессиональной подготовки [КОД] | ПО_П_ | Профессиональное обучение — Подготовка |
| профессессиональной переподготовки [КОД] | ПО_ПП_ | Профессиональное обучение — Переподготовка |
| повышение квалификации [КОД] | ПО_КПК_ | Профессиональное обучение — Повышение квалификации |

**Формат имени подпапки:** `[вид обучения] [код ОКПДТР] [название профессии]`

---

## 2. Обязательный набор документов в каждой подпапке

Каждая подпапка должна содержать **строго 6 основных документов + 20 лекций + тесты (только КПК)**:

| № | Файл | Описание | Обязательность |
|---|---|---|---|
| 00 | Программа | Сводный мега-документ (содержит Паспорт + Учебный план + ФОС) | Обязательно |
| 01 | Паспорт | Паспорт основной программы | Обязательно |
| 02 | Учебный план | Учебный план + Календарный график | Обязательно |
| 03 | ФОС ОП.0.0 | Фонд оценочных средств по общепрофессиональному циклу (20 вопросов + ключ) | Обязательно |
| 04 | ФОС МДК01.01 | Фонд оценочных средств по профессиональному циклу (20 вопросов + ключ) | Обязательно |
| 05 | ФОС итоговый | Фонд оценочных средств итоговой аттестации (20 вопросов + 15 билетов + матрица ответов) | Обязательно |
| — | Лекции ОП.01–ОП.08 | 8 лекций по общепрофессиональным дисциплинам | Обязательно |
| — | Лекции МДК 01.01 01–12 | 12 лекций по междисциплинарному курсу | Обязательно |
| — | Тест (только КПК) | Тестовые задания по разрядам (4/5/6 или соответствующие) | Только КПК |

## 3. Правила именования файлов

### 3.1 Основные документы
```
[NN]. [Префикс]_[Тип документа]_[Профессия]_[Разряды].docx
```

- **NN** — двухзначный номер: 00, 01, 02, 03, 04, 05
- **Префикс**: ПО_П_ / ПО_ПП_ / ПО_КПК_
- **Тип документа**: Программа / Паспорт / Учебный_план / ФОС
- **Профессия**: краткое название (слесарь КИПиА, Наладчик КИПиА, Оператор станков)
- **Разряды**: X-Y_разр (например, 2-3_разр, 4-6_разр)

Примеры:
- `00.Программа_ПО_П_КИП.docx`
- `01.ПО_П_Паспорт_слесарь КИПиА_2-3_разр.docx`
- `02. ПО_П_Учебный_план_слесарь КИПиА_2-3_разр.docx`
- `03. ПО_П_ФОС_слесарь КИПиА_2-3_разр ОП.0.0.docx`
- `04. ПО_П_ФОС_слесарь КИПиА_2-3_разр МДК01.01.docx`
- `05. ПО_П_ФОС_слесарь КИПиА_2-3_разр.docx`

### 3.2 Лекции ОП
```
Лекции ОП.XX. [Название дисциплины].docx
```
Пример: `Лекции ОП.01. Охрана труда, электробезопасность, пожарная и экологическая безопасность.docx`

### 3.3 Лекции МДК
```
Лекции МДК 01.01  [NN] [Название темы].docx
```
Пример: `Лекции МДК 01.01  01 Производство и распределение электроэнергии.docx`

**Внимание:** перед номером темы ставятся **два пробела**.

### 3.4 Тесты (КПК)
```
Тест/Тест [N] разряд.docx
```
Пример: `Тест 4 разряд.docx`, `Тест 5 разряд.docx`, `Тест 6 разряд.docx`

## 4. Структура каждого типа документа

### 4.1 Программа (00) — мега-документ
Содержит ВСЕ остальные документы в одном файле:
1. Титульная страница (ООО УЦ «ПрофСтрой»)
2. Таблица утверждения (ПРИНЯТО / УТВЕРЖДАЮ)
3. Информационная таблица (Профессия / Квалификация / Код ОКПДТР)
4. Оглавление
5. Раздел «Паспорт» (нормативная основа, объём, сроки, требования)
6. Планируемые результаты (таблицы компетенций по разрядам)
7. Учебный план (таблица дисциплин с часами)
8. Календарный учебный график (понедельное расписание)
9. Содержание программы (подробное описание каждой дисциплины)
10. Организационно-педагогические условия (оборудование, кадры)
11. ФОС (встроенные ключи ответов и матрицы билетов)

### 4.2 Паспорт (01)
Одна таблица со строками:
- Нормативно-правовая основа
- Объём программы (часы)
- Срок реализации (недели/дни)
- Форма обучения
- Режим занятий
- Требования к образованию и обучению
- Требования к опыту практической работы
- Периодичность обучения (только КПК)
- Цели обучения
- Формы контроля
- Итоговая аттестация

### 4.3 Учебный план (02)
1. Таблица утверждения
2. Таблица учебного плана (столбцы: №, Наименование, Всего часов, теор./практ., Форма контроля)
3. Календарный учебный график (понедельное распределение)
4. Легенда (ТЗ, ПЗ, СР, ПА, ИА)

### 4.4 ФОС ОП.0.0 (03)
1. Заголовок: «Фонд оценочных средств промежуточной аттестации по общепрофессиональному циклу (ОП.0.0)»
2. Приложение 4.2 (с указанием вида обучения: ПО (П) / ПО (ПП) / ПО (КПК))
3. 20 тестовых вопросов (а/б/в/г) по всем дисциплинам ОП.01–ОП.08
4. Таблица ответов

### 4.5 ФОС МДК01.01 (04)
1. Заголовок: «Фонд оценочных средств промежуточной аттестации (МДК01.01) по профессиональному циклу»
2. Приложение 4.2
3. 20 тестовых вопросов по темам МДК 01.01
4. Таблица ответов

### 4.6 ФОС итоговый (05)
1. Заголовок: «Фонд оценочных средств итоговой аттестации»
2. Приложение 4.3
3. 20 тестовых вопросов
4. Таблица ответов
5. 15 билетов по 20 вопросов каждый
6. Матрица ответов (строки = Билет №, столбцы = Вопросы 1–20)

### 4.7 Лекции
1. Заголовок: «Комплект лекций по междисциплинарному курсу [название МДК]»
2. Подзаголовок: «Для профессии [код] "[Профессия]" ([вида обучения] на [X-Y] разряды)»
3. Разделы-лекции:
   - Продолжительность: X академических часов
   - Цель лекции
   - Нумерованные подразделы (1.1., 1.2., и т.д.)
   - Встроенные таблицы
   - «Вопросы для повторения» в конце каждой лекции

#### 4.7.1 Минимальные требования к объёму и содержанию каждой лекции

**Объём:** текстовое содержимое каждой лекции должно составлять **не менее 5000 символов** (без учёта пробелов и служебных элементов). Для проверки: 5000 символов ≈ 2–3 страницы текста 12 пт.

**Таблицы:** каждая лекция должна содержать **минимум 2 таблицы**. Таблицы могут быть:
- Сравнительные таблицы (например, характеристики приборов, виды работ)
- Классификационные таблицы (типы, категории, разряды)
- Справочные таблицы (параметры, допуски, нормативы)
- Таблицы алгоритмов (последовательность действий)
- Таблицы «Причина — Следствие» или «Неисправность — Способ устранения»

**Графики / схемы:** каждая лекция должна содержать **минимум 1 график или схему** по возможности. Допускаются:
- Диаграммы (столбчатые, круговые, линейные)
- Графики зависимостей (характеристики приборов, кривые регулирования)
- Блок-схемы алгоритмов (последовательность наладки, испытаний)
- Структурные схемы (состав систем КИПиА, АСУ ТП)
- Принципиальные электрические схемы (фрагменты)
- Временные диаграммы (процессы регулирования)

**Исключение:** лекции, носящие преимущественно организационно-правовой характер (например, Охрана труда), могут содержать схемы вместо графиков.

#### 4.7.2 Типовая структура одной лекции внутри файла

```
Лекция [N]. [Название темы]
Продолжительность: X академических часов

1. [Введение / Общие положения]
   1.1. [Подраздел]
   1.2. [Подраздел]
   Таблица 1. [Название таблицы]

2. [Основная часть]
   2.1. [Подраздел]
   2.2. [Подраздел]
   Таблица 2. [Название таблицы]

3. [Практические аспекты / Примеры]
   [График / Схема / Диаграмма]

Вопросы для повторения:
1. ...
2. ...
```

## 8. Типовые ошибки копирования (на что обратить внимание!)

### 8.1 Заголовки календарного графика
В Учебных планах заголовок календарного графика должен содержать **правильный код и название профессии**. Частая ошибка — остаётся название от другой профессии.

### 8.2 Названия дисциплин в календарном графике
Должны **полностью совпадать** с названиями в таблице учебного плана. Ошибка: в учебном плане «Основы метрологии», а в графике «Общая технология производства».

### 8.3 Содержание Программы (мега-документ)
Весь текст внутри Программы должен соответствовать конкретной профессии. Ошибка: Программа для Наладчика содержит текст «Монтаж, обслуживание и ремонт» вместо «Наладка, испытания и сдача».

### 8.4 Приложение в ФОС
В ФОС заголовок «Приложение 4.2 к основной программе ПО (П)» должен меняться:
- П → «ПО (П)»
- ПП → «ПО (ПП)»
- КПК → «ПО (КПК)»

### 8.5 Разряды в подзаголовках лекций
Должны соответствовать виду обучения:
- П/ПП для Слесаря: «на 2-3 разряды»
- КПК для Слесаря: «на 4-6 разряды»
- П/ПП для Наладчика: «на 4-5 разряды»
- КПК для Наладчика: «на 6-7 разряды»

### 8.6 Практика в календарном графике
Детальный перечень практических работ должен соответствовать профессии. Нельзя оставлять перечень от другой профессии.

### 8.7 Согласованность часов в лекциях с учебным планом
Каждая лекция содержит поле «Продолжительность: X академических часов». Это значение **обязано совпадать** с количеством часов, отведённым на данную дисциплину/тему в Учебном плане (02). Правила проверки:

1. **Лекции ОП.01–ОП.08:** часы в лекции = часы из строки соответствующей дисциплины в столбце «Всего» таблицы учебного плана. При этом учитывается вид обучения:
   - П (Подготовка): ОП.00 = 36 ч → распределено по 8 дисциплинам
   - ПП (Переподготовка): ОП.00 = 24 ч → распределено по 8 дисциплинам
   - КПК (Повышение квалификации): ОП.00 = 12 ч → распределено по 8 дисциплинам

2. **Лекции МДК 01.01 (01–12):** часы в лекции = часы из строки соответствующей темы в столбце «Всего» учебного плана. Каждая из 12 тем имеет индивидуальное количество часов, которое масштабируется по виду обучения:
   - П: МДК 01.01 = 72 ч (сумма всех 12 тем)
   - ПП: МДК 01.01 = 36 ч
   - КПК: МДК 01.01 = 16 ч

3. **Тема 12 (Промежуточная аттестация):** как правило, 2–6 часов в зависимости от вида обучения.

4. **Часы должны быть целым числом**, кратным академическому часу (45 мин).

5. **Сумма часов всех лекций одной группы** (ОП или МДК) должна равняться итоговому количеству часов по данной дисциплине в учебном плане.

**Типичная ошибка:** лекция из папки П (Подготовка, 288 ч) содержит часы, соответствующие ПП или КПК, или наоборот. Это происходит при копировании лекций между подпапками без корректировки часов.
