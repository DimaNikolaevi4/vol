## Блок 1. Однозначность формулировок вопросов

> Проверяется **каждый вопрос** всех билетов.

| № | Критерий | Что искать | Статус | Примечание |
|---|---|---|---|---|
| 1.1 | Вопрос допускает **единственное** толкование | Отсутствие слов «обычно», «как правило», «чаще всего», «в основном», «как правило», «может», которые размывают границу ответа | | |
| 1.2 | В вопросе нет **скрытого двойного отрицания** | Формулировки вида «Какой параметр НЕ показывает…» при наличии варианта «ни один из перечисленных» | | |
| 1.3 | Вопрос не содержит **подсказки** в формулировке | Ключевое слово вопроса не повторяется дословно только в одном из вариантов ответа | | |
| 1.4 | Терминология вопроса **однозначна** и соответствует нормативным документам (ГОСТ, ПУЭ, СНиП, ФНП и др.) | Нет бытовых синонимов, устаревших терминов, не закреплённых в НПА | | |
| 1.5 | Вопрос **не зависит от контекста**, не указанного в условии | Не требуется знание конкретной модели прибора, типа сети, марки оборудования, если это не указано в самом вопросе | | |
| 1.6 | В вопросах с числовыми значениями указаны **конкретные цифры**, а не диапазоны (если иное не предусмотрено нормой) | «Не менее 0,5 МОм» допустимо только если норма именно такая; недопустимо «примерно 10 А» | | |
| 1.7 | Отсутствуют **вопросы-ловушки** с подменой понятий | Например, вопрос о «калибровке», а в правильном ответе — про «поверку» | | |

## Блок 2. Единственность и корректность правильного ответа

> Проверяется **каждый вопрос** всех билетов.

| № | Критерий | Что искать | Статус | Примечание |
> |---|---|---|---|---|
| 2.1 | Среди предложенных вариантов **только один** является верным | Нет двух вариантов, которые можно обосновать как правильные при разных трактовках | | |
| 2.2 | Правильный ответ **полностью** соответствует нормативному документу | Указан конкретный пункт ГОСТ / ПУЭ / ФНП / РД / ФЗ в обосновании | | |
| 2.3 | Ни один дистрактор **не является частично верным** | Исключены формулировки «в некоторых случаях верно», «для отдельных типов допустимо» | | |
| 2.4 | Правильный ответ **не является** наиболее общим/размытым из всех вариантов | Иначе экзаменуемый выберет его по логике «самый безопасный / самый длинный» | | |
| 2.5 | Все варианты ответов **взаимоисключающие** (не перекрываются по смыслу) | Варианты не должны быть вложены друг в друга (родо-видовые отношения) | | |
| 2.6 | Длина и детализация вариантов ответов **сопоставимы** | Правильный ответ не выделяется визуально (объёмом, детальностью формулировки) | | |

1. **Заполнить Паспорт проверки** (профессия, разряд, файл ФОС).
2. **Блок 3** — определить темы вопросов ФОС, заполнить таблицу нормативных источников (добавить/удалить строки).
