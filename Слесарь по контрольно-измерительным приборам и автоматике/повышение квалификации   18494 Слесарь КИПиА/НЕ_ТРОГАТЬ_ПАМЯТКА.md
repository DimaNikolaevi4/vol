# НЕ ТРОГАТЬ — памятка для правок программы 18494

Добавлено 25.11.2026 по указанию пользователя. Правила действуют во всех будущих сессиях.

## 1. Оглавление / «Содержание» — не делать жирным

- **Никогда не делать жирным текст оглавления (раздел «Содержание» / TOC).**
- Пользователь уже **трижды** вручную убирал жирное из оглавления — значит, оно возвращалось после моих действий.
- Обновление полей/TOC через Word также может вернуть жирное. Поэтому:
  - не запускать обновление TOC без крайней необходимости;
  - если обновление нужно — после него проверить, что оглавление **не жирное**, и не трогать его вручную;
  - не переформатировать абзацы TOC (не менять `w:b`, не применять стили «жирный»).
- Это правило важнее «актуальности» номеров страниц.

## 2. Текст, который пользователь правит сам, — не трогать

- **2.1 «Учебный план очной формы обучения»** — таблица приведена пользователем вручную в нормальное состояние. Не изменять.
- Любые фрагменты, которые пользователь правит сам, трогать запрещено без явной новой команды.

2. **Объём ИА в 5.4.1.2**: «4 ч + 2 ч + 1 ч комиссии» при «Объём — 6 часов», а также «2 час». **Не исправлять**.

## 4. Общее правило

Если пользователь говорит «не трогай» — это полный запрет на любые правки в указанном месте, включая форматирование, нумерацию и «очевидные» исправления. При сомнении — не трогать.
